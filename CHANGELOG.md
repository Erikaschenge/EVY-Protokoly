# CHANGELOG

## v0.6.0-alpha.3.1

- Balíky protokolov boli integrované do Správy protokolov ako záložky vozňov a jednotiek.
- Odstránený odkaz Balíky protokolov z hlavného menu.
- Pridané vytvorenie, úprava, duplikovanie a odstránenie záložiek.
- Pridané číselné pravidlá <, <=, >, >=, =, rozsah a tolerancia vrátane jednotky a náhľadu predpisu.
- Doplnené automatické OK/NOK vyhodnotenie ostrých aj neostrých hraníc.
- Rozšírený Excel import o nové operátory.

## v0.6.0-alpha.3.2

- Opravené osirelé protokoly po odstránení ich šablóny.
- Pridané bezpečné odstránenie neplatného odkazu priamo zo súpravy.
